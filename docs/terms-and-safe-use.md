# Terms and safe use

Not legal advice. Terms change; read the current ones yourself.

| Pattern | Status |
|---|---|
| One person, own machine, own login, interactive personal use via loopback | The only pattern this repo documents |
| Scheduled/unattended automation, bots serving others, team or multi-user access | Use Anthropic API keys instead |
| Hosted or public endpoint, shared/resold access, pooling accounts, routing others through your subscription | Do not do this; not supported by this project |
| Publishing OAuth tokens, credential directories, or proxy ports | Never |

If you are unsure whether your use is permitted, use API keys.
